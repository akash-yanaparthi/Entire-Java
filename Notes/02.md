# Java Basics

## 1. Java Statements

In Java, most statements end with a **semicolon (`;`)**.

For example:

```java
int age = 25;
System.out.println(age);
```

The semicolon tells Java that the statement has ended.

> **Note:** Not every Java construct requires a semicolon. For example, class declarations, method declarations, `if` blocks, `for` loops, and `while` loops do not end with a semicolon after their closing `}`.

---

# 2. Variables

A **variable** is a named memory location used to store data.

### Syntax

```java
dataType variableName = value;
```

### Example

```java
int age = 25;
String name = "John";
double salary = 50000.50;
```

Here:

* `int`, `String`, and `double` are data types.
* `age`, `name`, and `salary` are variable names.
* `25`, `"John"`, and `50000.50` are values.

### Changing a Variable's Value

```java
int age = 25;

age = 30;

System.out.println(age);
```

Output:

```text
30
```

# 3. Data Types

A data type specifies what kind of value a variable can store.

Java data types are mainly divided into two categories:

```text
Data Types
├── Primitive Data Types
└── Non-Primitive Data Types
```

## 3.1 Primitive Data Types

Java has **8 primitive data types**:

| Data Type |          Size | Example                      |
| --------- | ------------: | ---------------------------- |
| `byte`    |         8-bit | `byte b = 10;`               |
| `short`   |        16-bit | `short s = 100;`             |
| `int`     |        32-bit | `int age = 25;`              |
| `long`    |        64-bit | `long population = 100000L;` |
| `float`   |        32-bit | `float price = 10.5f;`       |
| `double`  |        64-bit | `double salary = 50000.50;`  |
| `char`    |        16-bit | `char grade = 'A';`          |
| `boolean` | JVM-dependent | `boolean isActive = true;`   |

### Integer Types

The integer data types are:

```text
byte
short
int
long
```

Example:

```java
byte age = 25;
short year = 2026;
int salary = 50000;
long population = 8000000000L;
```

For a `long` literal, we commonly add `L`:

```java
long number = 100000L;
```

### Floating-Point Types

The floating-point data types are:

```text
float
double
```

By default, a decimal floating-point literal is treated as a `double`.

For example:

```java
double price = 10.5;
```

If we want to store the value as a `float`, we need to add `f` or `F`:

```java
float price = 10.5f;
```

Without `f`:

```java
float price = 10.5;   // Error
```

With `f`:

```java
float price = 10.5f;  // Correct
```

# 4. Operators

Operators are symbols used to perform operations on values and variables.

Java provides several types of operators.

## 4.1 Arithmetic Operators

| Operator | Meaning        | Example |
| -------- | -------------- | ------- |
| `+`      | Addition       | `a + b` |
| `-`      | Subtraction    | `a - b` |
| `*`      | Multiplication | `a * b` |
| `/`      | Division       | `a / b` |
| `%`      | Modulus        | `a % b` |

Example:

```java
int a = 10;
int b = 3;

System.out.println(a + b); // 13
System.out.println(a - b); // 7
System.out.println(a * b); // 30
System.out.println(a / b); // 3
System.out.println(a % b); // 1
```

## 4.2 Assignment Operators

Assignment operators are used to assign or update values.

```java
int a = 10;

a += 5;  // a = a + 5
a -= 2;  // a = a - 2
a *= 3;  // a = a * 3
a /= 2;  // a = a / 2
a %= 2;  // a = a % 2
```

## 4.3 Relational Operators

Relational operators compare two values.

| Operator | Meaning                  |
| -------- | ------------------------ |
| `==`     | Equal to                 |
| `!=`     | Not equal to             |
| `>`      | Greater than             |
| `<`      | Less than                |
| `>=`     | Greater than or equal to |
| `<=`     | Less than or equal to    |

Example:

```java
int a = 10;
int b = 20;

System.out.println(a < b);
```

Output:

```text
true
```

## 4.4 Logical Operators

Logical operators are commonly used with conditions.

| Operator | Meaning     |   |            |
| -------- | ----------- | - | ---------- |
| `&&`     | Logical AND |   |            |
| `        |             | ` | Logical OR |
| `!`      | Logical NOT |   |            |

Example:

```java
int age = 25;

System.out.println(age > 18 && age < 60);
```

Output:

```text
true
```

# 5. Increment and Decrement Operators

The increment operator (`++`) increases a value by `1`.

The decrement operator (`--`) decreases a value by `1`.

```java
int a = 10;

a++;
System.out.println(a); // 11

a--;
System.out.println(a); // 10
```

There are two forms:

```text
Pre-increment
Post-increment
```

## 5.1 Pre-Increment

In pre-increment, the value is increased **before** it is used.

```java
int a = 10;

int b = ++a;
```

Execution:

```text
a becomes 11
b gets 11
```

So:

```java
System.out.println(a); // 11
System.out.println(b); // 11
```

## 5.2 Post-Increment

In post-increment, the current value is used **first**, and then the value is increased.

```java
int a = 10;

int b = a++;
```

Execution:

```text
b gets 10
a becomes 11
```

So:

```java
System.out.println(a); // 11
System.out.println(b); // 10
```

### Quick Difference

```text
++a  → Increment first, then use
a++  → Use first, then increment
```

The same concept applies to decrement:

```text
--a  → Decrement first, then use
a--  → Use first, then decrement
```

# 6. Type Conversion and Type Casting

Type conversion means converting a value from one data type to another.

There are two common forms:

```text
Type Conversion
├── Implicit Conversion
└── Explicit Conversion (Casting)
```

## 6.1 Implicit Type Conversion

Implicit conversion happens automatically when converting from a smaller compatible numeric type to a larger numeric type.

This is also called **widening conversion**.

```java
int a = 10;

double b = a;
```

Here, Java automatically converts:

```text
int → double
```

Example:

```java
int number = 100;

double result = number;

System.out.println(result);
```

Output:

```text
100.0
```

A common widening sequence is:

```text
byte
  ↓
short
  ↓
int
  ↓
long
  ↓
float
  ↓
double
```

`char` can also participate in numeric widening conversions.

---

# 7. Explicit Type Casting

Explicit casting is used when we manually convert a value from one type to another.

This is commonly called **narrowing conversion**.

### Syntax

```java
targetType variable = (targetType) value;
```

Example:

```java
double price = 10.99;

int value = (int) price;

System.out.println(value);
```

Output:

```text
10
```

The decimal portion is discarded.

Another example:

```java
double number = 100.50;

int result = (int) number;
```

Here:

```text
double → int
```

The conversion must be explicitly specified:

```java
(int) number
```

> **Important:** Narrowing conversions can result in loss of information, such as decimal digits or values outside the target type's range.

# 8. Conditional Statements

Conditional statements are used when we want the program to make decisions based on conditions.

Java provides:

```text
if
if-else
else-if
switch
```

## 8.1 if Statement

The `if` statement executes a block of code when the condition is `true`.

```java
int age = 20;

if (age >= 18) {
    System.out.println("Adult");
}
```

## 8.2 if-else Statement

```java
int age = 16;

if (age >= 18) {
    System.out.println("Adult");
} else {
    System.out.println("Minor");
}
```

## 8.3 else-if

The `else-if` structure is used when there are multiple conditions.

```java
int marks = 75;

if (marks >= 90) {
    System.out.println("A");
} else if (marks >= 75) {
    System.out.println("B");
} else if (marks >= 50) {
    System.out.println("C");
} else {
    System.out.println("Fail");
}
```

# 9. Loops

Loops are used to execute a block of code repeatedly.

Java provides:

```text
for loop
while loop
do-while loop
```

## 9.1 for Loop

A `for` loop is commonly used when we know how many times we want to execute a block.

```java
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```

Output:

```text
1
2
3
4
5
```

The structure is:

```java
for (initialization; condition; update) {
    // code
}
```

---

# 10. while Loop

A `while` loop executes as long as the condition is `true`.

```java
int i = 1;

while (i <= 5) {
    System.out.println(i);
    i++;
}
```

---

# 11. do-while Loop

A `do-while` loop executes the block **at least once**, because the condition is checked after the block executes.

```java
int i = 1;

do {
    System.out.println(i);
    i++;
} while (i <= 5);
```

The basic structure is:

```java
do {
    // code
} while (condition);
```

# 12. switch Statement

The `switch` statement is used to select one block of code from multiple possible cases.

Example:

```java
int day = 2;

switch (day) {
    case 1:
        System.out.println("Monday");
        break;

    case 2:
        System.out.println("Tuesday");
        break;

    case 3:
        System.out.println("Wednesday");
        break;

    default:
        System.out.println("Invalid day");
}
```

Output:

```text
Tuesday
```

## Why Do We Use `break`?

The `break` statement terminates the current `switch` statement.

Without `break`, execution can continue into the following cases. This behavior is called **fall-through**.

Example:

```java
int day = 2;

switch (day) {
    case 1:
        System.out.println("Monday");
        break;

    case 2:
        System.out.println("Tuesday");
        break;

    case 3:
        System.out.println("Wednesday");
        break;

    default:
        System.out.println("Invalid");
}
```

When `day` is `2`, Java executes:

```text
case 2
   ↓
Print Tuesday
   ↓
break
   ↓
Exit switch
```
