# Java Functions, Classes, and Objects

## 1. Functions in Java

A **function** is a block of code designed to perform a specific task.

In Java, functions are called **methods**.

For example, if we want to calculate the sum of two numbers, we can create a method:

```java
public static int add(int a, int b) {
    return a + b;
}
```

We can call this method from another method:

```java
public class Calculator {

    public static int add(int a, int b) {
        return a + b;
    }

    public static void main(String[] args) {

        int result = add(10, 20);

        System.out.println(result);
    }
}
```

Output:

```text
30
```

### Why Do We Use Methods?

Methods help us:

* Reuse code
* Organize code
* Avoid writing the same code repeatedly
* Make programs easier to understand and maintain

For example, instead of writing the addition logic multiple times:

```java
int result1 = 10 + 20;
int result2 = 30 + 40;
int result3 = 50 + 60;
```

We can create one method:

```java
public static int add(int a, int b) {
    return a + b;
}
```

Then reuse it:

```java
add(10, 20);
add(30, 40);
add(50, 60);
```

# 2. Object-Oriented Programming

**Object-Oriented Programming (OOP)** is a programming approach where we organize programs around **objects**.

Java is primarily an object-oriented programming language.

The basic idea is:

```text
Class
  ↓
Object
  ↓
Object contains
  ├── Properties
  └── Behaviors
```

Let's understand this with a real-world example.

---

# 3. Real-World Example: Car

Think about a **car**.

A car has certain properties:

```text
Properties
-----------
Color
Brand
Model
Speed
```

A car can also perform certain actions:

```text
Behaviors
-----------
Start
Stop
Accelerate
Brake
```

In Java, we can represent this using a class.

```java
class Car {

    // Properties
    String color;
    String brand;
    int speed;

    // Behavior
    void start() {
        System.out.println("Car is starting");
    }

    void accelerate() {
        System.out.println("Car is accelerating");
    }
}
```

Here:

```text
color
brand
speed
```

represent the **properties/state** of the car.

And:

```text
start()
accelerate()
```

represent the **behaviors/actions** of the car.

---

# 4. What Is a Class?

A **class is a blueprint or template used to create objects**.

For example, consider a house blueprint.

The blueprint describes:

```text
Number of rooms
Room locations
Doors
Windows
Kitchen
Bathroom
```

But the blueprint itself is not an actual house.

It is a plan for creating houses.

Similarly:

```text
Class = Blueprint
Object = Actual thing created from the blueprint
```

For example:

```java
class Car {
    String color;
    String brand;

    void start() {
        System.out.println("Car started");
    }
}
```

`Car` is a class.

It describes what a car object can have and what it can do.

---

# 5. What Is an Object?

An **object is an instance of a class**.

If `Car` is the blueprint, then an actual car created from that blueprint is an object.

```text
Class
 Car
  │
  ├── Object 1
  ├── Object 2
  └── Object 3
```

For example:

```java
Car car1 = new Car();
Car car2 = new Car();
Car car3 = new Car();
```

Here:

```text
Car
```

is the class.

And:

```text
car1
car2
car3
```

refer to individual objects.

Each object can have its own property values.

---

# 6. Properties and Behaviors

Objects generally have:

```text
State / Properties
       +
Behavior / Methods
```

For example:

```java
class Student {

    // Properties
    String name;
    int age;

    // Behavior
    void study() {
        System.out.println(name + " is studying");
    }
}
```

Here:

### Properties

```java
String name;
int age;
```

These represent the **state/data** of a student object.

### Behavior

```java
void study()
```

This represents an action the student can perform.

# 7. Creating an Object

Let's create an object from the `Student` class.

```java
class Student {

    String name;
    int age;

    void study() {
        System.out.println(name + " is studying");
    }
}

public class Main {

    public static void main(String[] args) {

        Student student1 = new Student();

        student1.name = "Rahul";
        student1.age = 20;

        student1.study();
    }
}
```

Output:

```text
Rahul is studying
```

Let's break this line down:

```java
Student student1 = new Student();
```

There are several things happening here.

---

# 8. Understanding `Student student1 = new Student();`

Consider:

```java
Student student1 = new Student();
```

### `Student`

This is the **type** of the variable.

It tells Java that `student1` is intended to refer to a `Student` object.

### `student1`

This is the **reference variable**.

It can hold a reference to a `Student` object.

### `new`

The `new` keyword is used to create a new object.

```java
new Student()
```

creates a new `Student` object by invoking the class's constructor.

### `Student()`

This is a **constructor call**.

The constructor is used during object creation to initialize the object.

So, conceptually:

```text
Student student1 = new Student();
       │              │
       │              └── Creates a Student object
       │
       └── Reference variable
```

---

# 9. What Is an Instance?

An **instance** is an object created from a class.

For example:

```java
Student student1 = new Student();
Student student2 = new Student();
```

Here, both `student1` and `student2` refer to separate `Student` objects.

We can say:

```text
student1 → instance of Student
student2 → instance of Student
```

Or simply:

> `student1` and `student2` are references to separate instances of the `Student` class.

---

# 10. Multiple Objects From One Class

One class can be used to create many objects.

```java
class Student {

    String name;
    int age;
}
```

Now we can create multiple students:

```java
Student student1 = new Student();
Student student2 = new Student();
Student student3 = new Student();
```

Each object has its own instance fields:

```java
student1.name = "Rahul";
student1.age = 20;

student2.name = "Priya";
student2.age = 21;

student3.name = "Arun";
student3.age = 19;
```

Conceptually:

```text
                 Student Class
                      │
          ┌───────────┼───────────┐
          ↓           ↓           ↓
       Object 1    Object 2    Object 3
       Rahul       Priya       Arun
       age 20      age 21      age 19
```

The class provides the structure, while each object has its own instance state.

# 11. How Do We Create an Object?

The common syntax is:

```java

```

For example:

```java
Car myCar = new Car();
```

Another example:

```java
Student student = new Student();
```

Another:

```java
Employee employee = new Employee();
```

The general pattern is:

```text
ClassName variableName = new ClassName();
```

---

# 12. Who Creates the Object?

This is an important question.

The **programmer writes the code that requests object creation**, using the `new` keyword.

For example:

```java
Student student = new Student();
```

The `new` expression causes the JVM to create a new object at runtime.

Conceptually:

```text
Programmer
    ↓
writes: new Student()
    ↓
Java runtime / JVM
    ↓
creates the object
```

The exact memory-management details are handled by the Java runtime, including the JVM's memory management and garbage collector.

So we don't manually allocate and free memory like in languages such as C.

---

# 13. Who Creates the Blueprint?

The **programmer/developer creates the class**.

For example:

```java
class Student {

    String name;
    int age;

    void study() {
        System.out.println("Student is studying");
    }
}
```

The programmer has defined the `Student` class.

This class acts as the blueprint from which `Student` objects can be created.

So:

```text
Programmer
    ↓
Creates class
    ↓
Class acts as blueprint
    ↓
Objects are created from the class
```

# 14. Class vs Object

This is one of the most important concepts in OOP.

| Class                                   | Object                                    |
| --------------------------------------- | ----------------------------------------- |
| Blueprint/template                      | Actual instance                           |
| Defines structure and behavior          | Has actual state and can perform behavior |
| Used to create objects                  | Created from a class                      |
| Example: `Student`                      | Example: `student1`                       |
| Does not represent one specific student | Represents one particular student         |

### Real-World Example

Think about a cookie cutter.

```text
Cookie Cutter → Class
Cookie → Object
```

The cookie cutter defines the shape.

You can use the same cookie cutter to make many cookies:

```text
             Cookie Cutter
                  │
        ┌─────────┼─────────┐
        ↓         ↓         ↓
      Cookie    Cookie    Cookie
        1          2         3
```

Similarly:

```text
              Student Class
                   │
          ┌────────┼────────┐
          ↓        ↓        ↓
       Student   Student   Student
        Object     Object    Object
           1          2         3
```

# 15. A Complete Example

Let's combine everything.

```java
class Car {

    // Properties
    String brand;
    String color;
    int speed;

    // Behavior
    void start() {
        System.out.println(brand + " is starting");
    }

    void accelerate() {
        speed = speed + 10;
        System.out.println("Speed: " + speed);
    }
}

public class Main {

    public static void main(String[] args) {

        // Creating an object
        Car car1 = new Car();

        // Setting properties
        car1.brand = "Toyota";
        car1.color = "Red";
        car1.speed = 0;

        // Calling behaviors
        car1.start();
        car1.accelerate();
        car1.accelerate();
    }
}
```

Output:

```text
Toyota is starting
Speed: 10
Speed: 20
```

Let's understand the flow:

```text
class Car
    ↓
Programmer defines the blueprint
    ↓
new Car()
    ↓
JVM/runtime creates an object
    ↓
car1 refers to that object
    ↓
Properties are assigned
    ↓
Methods are called
```

# 17. Important Terminology

### Class

A blueprint/template that defines the structure and behavior of objects.

### Object

An instance created from a class.

### Instance

A specific object created from a class.

### Property / Field

Data associated with an object.

Example:

```java
String name;
int age;
```

### Behavior / Method

An action that an object can perform.

Example:

```java
void study() {
    System.out.println("Studying");
}
```

### `new` Keyword

Used to create a new object and invoke its constructor.

Example:

```java
Student student = new Student();
```

### Reference Variable

A variable that holds a reference to an object.

Example:

```java
Student student;
```

# 18. Final Picture

The complete concept can be remembered like this:

```text
                    PROGRAMMER
                        │
                        ↓
                  Creates a CLASS
                        │
                        ↓
                CLASS = BLUEPRINT
                        │
                        │
                  new keyword
                        │
                        ↓
                  OBJECT CREATED
                        │
              ┌─────────┴─────────┐
              ↓                   ↓
          Properties           Behaviors
           (State)             (Methods)
              │                   │
              ↓                   ↓
          name, age             study()
          color, speed          start()
```

### In One Sentence

> **A class is a blueprint created by the programmer, and objects are instances created from that class at runtime; objects contain state through fields and behavior through methods.**

This is the foundation of **Object-Oriented Programming (OOP)** in Java.
